# Blog Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A statically generated blog at `/blog` whose posts are Markdown files exported from `../content-engine`, each shipping full metadata, structured data, a feed entry and a raw-markdown alternate.

**Architecture:** `content/blog/` holds posts (`<slug>.md` or `<slug>/index.md` + `images/`). A server-only library, `src/lib/blog/`, validates front matter with a strict zod schema, renders Markdown through a `unified` pipeline to React elements (no client JS, no MDX), and exposes pure selectors for series and related posts. A prebuild script copies post images and writes `.md` alternates into `public/blog/`. Blog routes join `src/lib/routes.ts`, so the sitemap, OG cards, SEO gate and e2e suites from plan 1 cover them automatically.

**Tech Stack:** (on top of plan 1) `unified` 11, `remark-parse` 11, `remark-gfm` 4, `remark-rehype` 11, `rehype-slug` 6, `rehype-autolink-headings` 7, `rehype-stringify` 10, `@shikijs/rehype` 4, `hast-util-to-jsx-runtime` 2, `hast-util-to-string` 3, `unist-util-visit` 5, `gray-matter` 4, `zod` 4, `image-size` 2; Netlify Image CDN through a custom `next/image` loader.

**Spec:** `docs/superpowers/specs/2026-09-20-blog-design.md`

**Prerequisite:** plan `2026-09-20-next-migration.md` is complete and merged. ## Global Constraints

- **Git is read-only for the agent.** Every "Commit" step means: print the exact commands and ask Brian to run them. Work on branch `blog` (Brian creates it: `git checkout -b blog`).
- `npm`, Node 22. Definition of done for every task: `npm test` → `npm run lint` → `npm run build` → `npm run e2e`, all green.
- No MDX, and no raw HTML from posts ever reaches the page. Post content is drafted by agents from web pages; nothing in a post may execute.
- The front-matter schema is **strict**: unknown keys fail the build.
- Every image needs alt text; a missing image file, missing alt, or an image reference that is not `./images/<name>.<ext>` fails the build.
- `.svg` images render as plain `<img>` and never go through `next/image`.
- Vanilla CSS using the `index.css` custom properties. All blog styles live in one file, `src/components/blog/blog.css` (the same one-stylesheet pattern as `WorkflowPage.css`).
- Blog components are server components. No `"use client"` anywhere in this plan except the image loader file, which Next requires.
- Posts are bylined to Brian Flannery (`Person`); the publisher is the `Organization`. No per-post author switch.
- Any markdown file created or edited under `docs/` or the repo root is also copied to `/Users/brian/Documents/dev-vault/projects/paradigm/consulting-website/<same relative path>`. Files under `content/blog/` and `e2e/fixtures/` are site content and test data — **not** copied.

## Deviations from the spec (decided at plan time, spec updated to match)

1. **Unit tests build throwaway content directories** with a helper instead of reading `src/lib/blog/__fixtures__/`; each case stays a few lines and cannot rot. On-disk fixture posts live in `e2e/fixtures/blog/` and are what the e2e build renders.
2. **The e2e build reads `BLOG_CONTENT_DIR=e2e/fixtures/blog`.** Production has no published post yet, so without this the post, series and feed pages could not be tested end to end.
3. **No separate "plain-text excerpt".** Cards, feeds and metadata all use `summary`; nothing needed an excerpt.
4. **RSS autodiscovery is a `<link>` in the root layout `<head>`,** not `metadata.alternates.types`: Next replaces the whole `alternates` object per page, so a root-level value would vanish on every page that sets a canonical.
5. **The Netlify Image CDN is switched on by `NEXT_PUBLIC_IMAGE_CDN=netlify`,** set only in `netlify.toml`. Local production builds (and Playwright) serve raw files, because `/.netlify/images` does not exist off Netlify.
6. **`image-size` reads SVG dimensions too** (from `width`/`height` or `viewBox`), so raster and SVG share one code path.

```ts
import { z } from "zod";
import { services } from "../../data/services";

const SLUG = /^[a-z0-9]+(?:-[a-z0-9]+)*$/;
const DATE = /^\d{4}-\d{2}-\d{2}$/;
const IMAGE_REF = /^\.\/images\/[A-Za-z0-9._-]+$/;

/** YAML turns a bare `2026-09-20` into a Date, and content-engine writes bare dates. */
const dateString = z.preprocess(
  (value) =>
    value instanceof Date && !Number.isNaN(value.getTime())
      ? value.toISOString().slice(0, 10)
      : value,
  z.string().regex(DATE, "must be YYYY-MM-DD"),
);

const serviceSlugs = services.map((s) => s.slug) as [string, ...string[]];

/**
 * Strict on purpose: a typo such as `service:` fails the build instead of being
 * ignored. Supporting a new content-engine key is a deliberate one-line change here.
 */
export const FrontMatter = z
  .strictObject({
    // — written by content-engine —
    title: z.string().trim().min(1),
    slug: z.string().regex(SLUG, "must be kebab-case"),
    date: dateString,
    tags: z.array(z.string().trim().min(1)).default([]),
    summary: z.string().trim().min(1, "required: it is the page's meta description"),
    series: z.string().trim().min(1).optional(),
    seriesSlug: z.string().regex(SLUG, "must be kebab-case").optional(),
    part: z.number().int().positive().optional(),
    partsTotal: z.number().int().positive().optional(),
    // Accepted and ignored: nextPart is stale until the earlier part is re-exported,
    // so the site derives neighbours from seriesSlug + part instead.
    previousPart: z.string().optional(),
    nextPart: z.string().optional(),
    // — added by hand after export —
    cover: z.string().regex(IMAGE_REF, "must be ./images/<name>.<ext>").optional(),
    coverAlt: z.string().trim().min(1).optional(),
    services: z.array(z.enum(serviceSlugs)).default([]),
    updated: dateString.optional(),
    draft: z.boolean().default(false),
  })
  .superRefine((fm, ctx) => {
    const seriesKeys = [fm.series, fm.seriesSlug, fm.part, fm.partsTotal];
    const present = seriesKeys.filter((v) => v !== undefined).length;
    if (present !== 0 && present !== seriesKeys.length) {
      ctx.addIssue({
        code: "custom",
        path: ["series"],
        message: "series, seriesSlug, part and partsTotal must all be set, or none",
      });
    }
    if (fm.part !== undefined && fm.partsTotal !== undefined && fm.part > fm.partsTotal) {
      ctx.addIssue({
        code: "custom",
        path: ["part"],
        message: `${fm.part} is greater than partsTotal ${fm.partsTotal}`,
      });
    }
    if (fm.cover !== undefined && fm.coverAlt === undefined) {
      ctx.addIssue({ code: "custom", path: ["coverAlt"], message: "required when cover is set" });
    }
    if (fm.updated !== undefined && fm.updated < fm.date) {
      ctx.addIssue({
        code: "custom",
        path: ["updated"],
        message: `${fm.updated} is before date ${fm.date}`,
      });
    }
  });

export type FrontMatter = z.infer<typeof FrontMatter>;

export type ParseResult =
  | { ok: true; value: FrontMatter }
  | { ok: false; problems: string[] };

export function parseFrontMatter(data: unknown): ParseResult {
  const result = FrontMatter.safeParse(data);
  if (result.success) return { ok: true, value: result.data };
  return {
    ok: false,
    problems: result.error.issues.map((issue) => {
      const where = issue.path.length > 0 ? issue.path.join(".") : "front matter";
      return `${where}: ${issue.message}`;
    }),
  };
}
```

```ts
import { existsSync, readFileSync, readdirSync } from "node:fs";
import { basename, join } from "node:path";
import matter from "gray-matter";
import { imageSize } from "image-size";
import { parseFrontMatter, type FrontMatter } from "./schema";

export interface Cover {
  src: string;
  alt: string;
  width: number;
  height: number;
}

export interface PostSource {
  slug: string;
  frontMatter: FrontMatter;
  /** Markdown body, still including the leading H1 content-engine writes. */
  body: string;
  /** Path relative to the content directory, for error messages. */
  file: string;
  /** Absolute path of `<slug>/images`, or null for a flat post. */
  imageDir: string | null;
  cover: Cover | null;
}

export class BlogContentError extends Error {
  constructor(public readonly problems: string[]) {
    super(`Blog content has ${problems.length} problem(s):\n${problems.map((p) => `  ✗ ${p}`).join("\n")}`);
    this.name = "BlogContentError";
  }
}

function rejectJsFrontMatter(): never {
  throw new Error("JavaScript front matter is not allowed");
}

/** gray-matter `eval`s `---js` front matter by default. Posts are agent-written: never. */
export const MATTER_OPTIONS = {
  engines: { js: rejectJsFrontMatter, javascript: rejectJsFrontMatter },
};

interface Candidate {
  name: string;
  file: string;
  path: string;
  imageDir: string | null;
}

function findCandidates(contentDir: string, problems: string[]): Candidate[] {
  const entries = readdirSync(contentDir, { withFileTypes: true }).filter(
    (entry) => !entry.name.startsWith("."),
  );
  const candidates: Candidate[] = [];
  for (const entry of entries) {
    if (entry.isDirectory()) {
      const index = join(contentDir, entry.name, "index.md");
      if (!existsSync(index)) {
        problems.push(`${entry.name}/: missing index.md`);
        continue;
      }
      candidates.push({
        name: entry.name,
        file: `${entry.name}/index.md`,
        path: index,
        imageDir: join(contentDir, entry.name, "images"),
      });
    } else if (entry.name.endsWith(".md")) {
      candidates.push({
        name: basename(entry.name, ".md"),
        file: entry.name,
        path: join(contentDir, entry.name),
        imageDir: null,
      });
    } else {
      problems.push(`${entry.name}: unexpected file (posts are .md files or folders)`);
    }
  }
  return candidates;
}

function resolveCover(candidate: Candidate, fm: FrontMatter, problems: string[]): Cover | null {
  if (!fm.cover || !fm.coverAlt) return null;
  if (!candidate.imageDir) {
    problems.push(
      `${candidate.file}: cover ${fm.cover} needs the folder layout (${candidate.name}/index.md + ${candidate.name}/images/)`,
    );
    return null;
  }
  const name = fm.cover.slice("./images/".length);
  const path = join(candidate.imageDir, name);
  if (!existsSync(path)) {
    problems.push(`${candidate.file}: cover ${fm.cover} does not exist`);
    return null;
  }
  const { width, height } = imageSize(readFileSync(path));
  if (!width || !height) {
    problems.push(`${candidate.file}: cover ${fm.cover} has no readable dimensions`);
    return null;
  }
  return { src: `/blog/${fm.slug}/images/${name}`, alt: fm.coverAlt, width, height };
}

function checkSeries(posts: PostSource[], problems: string[]): void {
  const bySeries = new Map<string, PostSource[]>();
  for (const p of posts) {
    const key = p.frontMatter.seriesSlug;
    if (key) bySeries.set(key, [...(bySeries.get(key) ?? []), p]);
  }
  for (const [seriesSlug, parts] of bySeries) {
    const byPart = new Map<number, string[]>();
    for (const p of parts) {
      const part = p.frontMatter.part as number;
      byPart.set(part, [...(byPart.get(part) ?? []), p.slug]);
    }
    for (const [part, slugs] of byPart) {
      if (slugs.length > 1) {
        problems.push(`series ${seriesSlug}: part ${part} is claimed by ${slugs.sort().join(" and ")}`);
      }
    }
    const shapes = new Set(parts.map((p) => `${p.frontMatter.series}|${p.frontMatter.partsTotal}`));
    if (shapes.size > 1) {
      const slugs = parts.map((p) => p.slug).sort().join(", ");
      problems.push(`series ${seriesSlug}: posts disagree on series title or partsTotal (${slugs})`);
    }
  }
}

export function loadPostSources(
  contentDir: string,
  options: { includeDrafts: boolean },
): PostSource[] {
  if (!existsSync(contentDir)) return [];

  const problems: string[] = [];
  const candidates = findCandidates(contentDir, problems);

  const names = new Map<string, number>();
  for (const c of candidates) names.set(c.name, (names.get(c.name) ?? 0) + 1);
  for (const [name, count] of names) {
    if (count > 1) problems.push(`${name}: exists as both ${name}.md and ${name}/index.md`);
  }

  const posts: PostSource[] = [];
  for (const candidate of candidates) {
    if ((names.get(candidate.name) ?? 0) > 1) continue;
    let parsed: { data: unknown; content: string };
    try {
      parsed = matter(readFileSync(candidate.path, "utf8"), MATTER_OPTIONS);
    } catch (error) {
      problems.push(`${candidate.file}: ${(error as Error).message}`);
      continue;
    }
    const result = parseFrontMatter(parsed.data);
    if (!result.ok) {
      problems.push(...result.problems.map((p) => `${candidate.file}: ${p}`));
      continue;
    }
    const fm = result.value;
    if (fm.slug !== candidate.name) {
      problems.push(`${candidate.file}: slug "${fm.slug}" must match the file name "${candidate.name}"`);
      continue;
    }
    posts.push({
      slug: fm.slug,
      frontMatter: fm,
      body: parsed.content.replace(/^\s*\n/, ""),
      file: candidate.file,
      imageDir: candidate.imageDir,
      cover: resolveCover(candidate, fm, problems),
    });
  }

  checkSeries(posts, problems);
  if (problems.length > 0) throw new BlogContentError(problems.sort());

  return posts
    .filter((p) => options.includeDrafts || !p.frontMatter.draft)
    .sort(
      (a, b) =>
        b.frontMatter.date.localeCompare(a.frontMatter.date) || a.slug.localeCompare(b.slug),
    );
}
```

```ts
import { existsSync, readFileSync } from "node:fs";
import { join } from "node:path";
import rehypeShiki from "@shikijs/rehype";
import matter from "gray-matter";
import type { Element, ElementContent, Root as HastRoot } from "hast";
import { toString as hastToString } from "hast-util-to-string";
import { imageSize } from "image-size";
import type { Root as MdastRoot } from "mdast";
import rehypeAutolinkHeadings from "rehype-autolink-headings";
import rehypeSlug from "rehype-slug";
import rehypeStringify from "rehype-stringify";
import remarkGfm from "remark-gfm";
import remarkParse from "remark-parse";
import remarkRehype from "remark-rehype";
import { unified } from "unified";
import { visit } from "unist-util-visit";
import { MATTER_OPTIONS, type PostSource } from "./load";

export interface TocEntry {
  id: string;
  text: string;
}

export interface RenderedPost {
  tree: HastRoot;
  toc: TocEntry[];
  readingMinutes: number;
}

const ANCHOR_CLASS = "post-anchor";
const IMAGE_REF = /^\.\/images\/([A-Za-z0-9._-]+)$/;
const WORDS_PER_MINUTE = 225;

/** content-engine opens every body with an H1 repeating the title; the page renders its own. */
function remarkStripTitle() {
  return (tree: MdastRoot) => {
    const first = tree.children[0];
    if (first?.type === "heading" && first.depth === 1) tree.children.shift();
    visit(tree, "heading", (node) => {
      if (node.depth === 1) {
        throw new Error("only the leading H1 is allowed; use H2 and below in the body");
      }
    });
  };
}

function rehypeExternalLinks(siteUrl: string) {
  return () => (tree: HastRoot) => {
    visit(tree, "element", (node: Element) => {
      const href = node.properties.href;
      if (node.tagName !== "a" || typeof href !== "string") return;
      if (/^https?:\/\//.test(href) && !href.startsWith(siteUrl)) {
        node.properties.target = "_blank";
        node.properties.rel = ["noopener", "noreferrer"];
      }
    });
  };
}

function rehypePostImages(slug: string, imageDir: string | null) {
  return () => (tree: HastRoot) => {
    visit(tree, "element", (node: Element) => {
      if (node.tagName !== "img") return;
      const src = String(node.properties.src ?? "");
      const match = IMAGE_REF.exec(src);
      if (!match) throw new Error(`image "${src}" must be referenced as ./images/<name>.<ext>`);
      if (!String(node.properties.alt ?? "").trim()) throw new Error(`image "${src}" has no alt text`);
      const file = imageDir ? join(imageDir, match[1]) : null;
      if (!file || !existsSync(file)) throw new Error(`image "${src}" does not exist`);
      const { width, height } = imageSize(readFileSync(file));
      if (!width || !height) throw new Error(`image "${src}" has no readable dimensions`);
      node.properties.src = `/blog/${slug}/images/${match[1]}`;
      node.properties.width = width;
      node.properties.height = height;
    });
  };
}

export async function renderMarkdown(
  post: Pick<PostSource, "slug" | "body" | "imageDir">,
  siteUrl: string,
): Promise<RenderedPost> {
  const processor = unified()
    .use(remarkParse)
    .use(remarkGfm)
    .use(remarkStripTitle)
    // No `allowDangerousHtml`: raw HTML in a post is dropped, never rendered.
    .use(remarkRehype)
    .use(rehypeSlug)
    .use(rehypeAutolinkHeadings, {
      behavior: "append",
      test: ["h2", "h3"],
      properties: { className: [ANCHOR_CLASS], ariaLabel: "Link to this section" },
      content: { type: "text", value: "#" },
    })
    .use(rehypeShiki, { theme: "github-light" })
    .use(rehypeExternalLinks(siteUrl))
    .use(rehypePostImages(post.slug, post.imageDir));

  let tree: HastRoot;
  try {
    tree = (await processor.run(processor.parse(post.body))) as HastRoot;
  } catch (error) {
    throw new Error(`blog post "${post.slug}": ${(error as Error).message}`);
  }

  const toc: TocEntry[] = [];
  visit(tree, "element", (node: Element) => {
    if (node.tagName === "h2" && typeof node.properties.id === "string") {
      toc.push({ id: node.properties.id, text: hastToString(node).replace(/#$/, "").trim() });
    }
  });

  const words = hastToString(tree).split(/\s+/).filter(Boolean).length;
  return { tree, toc, readingMinutes: Math.max(1, Math.ceil(words / WORDS_PER_MINUTE)) };
}

const isAnchor = (node: ElementContent): boolean =>
  node.type === "element" &&
  Array.isArray(node.properties.className) &&
  node.properties.className.includes(ANCHOR_CLASS);

/** Feed readers need absolute URLs and would show the "#" heading anchors as text. */
export function feedHtml(tree: HastRoot, siteUrl: string): string {
  const copy = structuredClone(tree);
  visit(copy, "element", (node: Element) => {
    node.children = node.children.filter((child) => !isAnchor(child));
    for (const key of ["href", "src"] as const) {
      const value = node.properties[key];
      if (typeof value === "string" && value.startsWith("/")) {
        node.properties[key] = `${siteUrl}${value}`;
      }
    }
  });
  return unified().use(rehypeStringify).stringify(copy);
}

/** The `/blog/<slug>.md` alternate: the post as plain markdown, for AI agents. */
export function cleanMarkdown(post: PostSource, siteUrl: string): string {
  const fm = post.frontMatter;
  const body = post.body.replace(
    /\]\(\.\/images\//g,
    `](${siteUrl}/blog/${post.slug}/images/`,
  );
  return matter.stringify(
    body,
    {
      title: fm.title,
      date: fm.date,
      ...(fm.updated ? { updated: fm.updated } : {}),
      summary: fm.summary,
      canonical: `${siteUrl}/blog/${post.slug}`,
    },
    MATTER_OPTIONS,
  );
}
```

```ts
import { SITE_URL } from "../../data/site";
import { loadPostSources, type PostSource } from "./load";
import { renderMarkdown, type RenderedPost } from "./markdown";

/** The e2e build points this at e2e/fixtures/blog. */
export const BLOG_CONTENT_DIR = process.env.BLOG_CONTENT_DIR ?? "content/blog";

const isProduction = process.env.NODE_ENV === "production";

let cached: PostSource[] | undefined;

/** Published posts, newest first. Drafts appear only outside production builds. */
export function getPosts(): PostSource[] {
  // Cache only in production: `next dev` should pick up a new post without a restart.
  if (cached && isProduction) return cached;
  cached = loadPostSources(BLOG_CONTENT_DIR, { includeDrafts: !isProduction });
  return cached;
}

export const hasPosts = (): boolean => getPosts().length > 0;

export const getPost = (slug: string): PostSource | undefined =>
  getPosts().find((p) => p.slug === slug);

const rendered = new Map<string, Promise<RenderedPost>>();

export function renderPost(post: PostSource): Promise<RenderedPost> {
  if (!isProduction) return renderMarkdown(post, SITE_URL);
  let result = rendered.get(post.slug);
  if (!result) {
    result = renderMarkdown(post, SITE_URL);
    rendered.set(post.slug, result);
  }
  return result;
}

export interface SeriesInfo {
  slug: string;
  title: string;
  partsTotal: number;
  /** Published parts only, ascending by part number. */
  parts: PostSource[];
}

const partOf = (post: PostSource): number => post.frontMatter.part ?? 0;

export function listSeries(posts: PostSource[]): SeriesInfo[] {
  const bySlug = new Map<string, SeriesInfo>();
  for (const post of posts) {
    const { seriesSlug, series, partsTotal } = post.frontMatter;
    if (!seriesSlug || !series || !partsTotal) continue;
    const info = bySlug.get(seriesSlug) ?? { slug: seriesSlug, title: series, partsTotal, parts: [] };
    info.parts.push(post);
    bySlug.set(seriesSlug, info);
  }
  return [...bySlug.values()].map((info) => ({
    ...info,
    parts: [...info.parts].sort((a, b) => partOf(a) - partOf(b)),
  }));
}

export const findSeries = (posts: PostSource[], seriesSlug: string): SeriesInfo | undefined =>
  listSeries(posts).find((s) => s.slug === seriesSlug);

/** Nearest published part on each side — a series may be published with gaps. */
export function seriesNeighbors(
  posts: PostSource[],
  post: PostSource,
): { previous: PostSource | null; next: PostSource | null } {
  const series = post.frontMatter.seriesSlug
    ? findSeries(posts, post.frontMatter.seriesSlug)
    : undefined;
  if (!series) return { previous: null, next: null };
  const index = series.parts.findIndex((p) => p.slug === post.slug);
  return {
    previous: series.parts[index - 1] ?? null,
    next: series.parts[index + 1] ?? null,
  };
}

const shared = (a: string[], b: string[]): number => a.filter((x) => b.includes(x)).length;

/** Up to `limit` other posts: shared services first, then shared tags, then newest. */
export function relatedPosts(posts: PostSource[], post: PostSource, limit = 3): PostSource[] {
  const { seriesSlug } = post.frontMatter;
  return posts
    .filter((p) => p.slug !== post.slug)
    .filter((p) => !seriesSlug || p.frontMatter.seriesSlug !== seriesSlug)
    .map((p, index) => ({
      post: p,
      index, // `posts` is newest-first, so a lower index is more recent
      services: shared(p.frontMatter.services, post.frontMatter.services),
      tags: shared(p.frontMatter.tags, post.frontMatter.tags),
    }))
    .sort((a, b) => b.services - a.services || b.tags - a.tags || a.index - b.index)
    .slice(0, limit)
    .map((entry) => entry.post);
}

export const postsForService = (
  posts: PostSource[],
  serviceSlug: string,
  limit = 3,
): PostSource[] =>
  posts.filter((p) => p.frontMatter.services.includes(serviceSlug)).slice(0, limit);
```

```ts
"use client";

interface LoaderArgs {
  src: string;
  width: number;
  quality?: number;
}

/**
 * next/image loader. On Netlify (NEXT_PUBLIC_IMAGE_CDN=netlify, set in netlify.toml)
 * images are resized and re-encoded by the Netlify Image CDN. Anywhere else —
 * `next dev`, a local `next build`, Playwright — `/.netlify/images` does not exist,
 * so the raw file is served.
 */
export default function imageLoader({ src, width, quality }: LoaderArgs): string {
  if (process.env.NEXT_PUBLIC_IMAGE_CDN === "netlify") {
    return `/.netlify/images?url=${encodeURIComponent(src)}&w=${width}&q=${quality ?? 75}`;
  }
  return `${src}?w=${width}`;
}
```

```ts
export interface PageMeta {
  title: string;
  description: string;
  path: string;
  /** Use `title` as the entire <title>, without the site suffix. */
  absoluteTitle?: boolean;
  /** Overrides the generated OG card (a post's cover). */
  image?: { url: string; width: number; height: number; alt: string };
  /** Present ⇒ Open Graph type "article". */
  article?: {
    publishedTime: string;
    modifiedTime: string;
    authors: string[];
    tags: string[];
  };
  /** Extra <link rel="alternate"> entries, by MIME type. */
  alternateTypes?: Record<string, string>;
  noindex?: boolean;
}

export function pageMetadata({
  title,
  description,
  path,
  absoluteTitle = false,
  image,
  article,
  alternateTypes,
  noindex = false,
}: PageMeta): Metadata {
  const fullTitle = absoluteTitle ? title : `${title} | ${SITE_SHORT_NAME}`;
  const card = image ?? { url: ogImagePath(path), width: 1200, height: 630, alt: title };
  return {
    title: absoluteTitle ? { absolute: title } : title,
    description,
    alternates: { canonical: path, ...(alternateTypes ? { types: alternateTypes } : {}) },
    ...(noindex ? { robots: { index: false, follow: true } } : {}),
    openGraph: {
      ...(article ? { type: "article" as const, ...article } : { type: "website" as const }),
      locale: "en_US",
      url: path,
      siteName: SITE_NAME,
      title: fullTitle,
      description,
      images: [card],
    },
    twitter: {
      card: "summary_large_image",
      title: fullTitle,
      description,
      images: [card.url],
    },
  };
}
```

```tsx
interface BlogImageProps {

  priority?: boolean;
  className?: string;
}

/** Raster images go through next/image (Netlify Image CDN). SVGs never do. */
const BlogImage = ({ src, alt, width, height, sizes, priority, className }: BlogImageProps) => {
  if (src.endsWith(".svg")) {
    return (
      // eslint-disable-next-line @next/next/no-img-element -- SVGs bypass the image CDN, and <img> sandboxes any script inside an agent-written SVG
      <img
        src={src}
        alt={alt}
        width={width}
        height={height}
        className={className}
        loading={priority ? "eager" : "lazy"}
        decoding="async"
      />
    );
  }
  return (
    <Image
      src={src}
      alt={alt}
      width={width}
      height={height}
      className={className}
      sizes={sizes ?? "(max-width: 800px) 100vw, 760px"}
      priority={priority}
    />
  );
};
```

```ts
import { author } from "../../data/author";
import type { PostSource } from "./load";
import { BLOG_PATH, FEED_PATH, postPath } from "./paths";
import { BLOG_META } from "./seo";

export interface FeedItem {
  post: PostSource;
  /** Body HTML with absolute URLs — see feedHtml(). */
  html: string;
}

const escapeXml = (text: string): string =>
  text
    .replace(/&/g, "&amp;")
    .replace(/</g, "&lt;")
    .replace(/>/g, "&gt;")
    .replace(/"/g, "&quot;");

/** A literal "]]>" would end the CDATA section early; split it across two sections. */
const cdata = (html: string): string => `<![CDATA[${html.replace(/]]>/g, "]]]]><![CDATA[>")}]]>`;

const rfc822 = (isoDate: string): string => new Date(`${isoDate}T00:00:00Z`).toUTCString();

/** RSS 2.0 with full content. `items` must be newest-first, as getPosts() returns them. */
export function buildFeed(items: FeedItem[], siteUrl: string): string {
  const newest = items[0]?.post.frontMatter;
  const entries = items.map(({ post, html }) => {
    const fm = post.frontMatter;
    const url = `${siteUrl}${postPath(post.slug)}`;
    return [
      "    <item>",
      `      <title>${escapeXml(fm.title)}</title>`,
      `      <link>${url}</link>`,
      `      <guid isPermaLink="true">${url}</guid>`,
      `      <pubDate>${rfc822(fm.date)}</pubDate>`,
      `      <dc:creator>${escapeXml(author.name)}</dc:creator>`,
      `      <description>${escapeXml(fm.summary)}</description>`,
      ...fm.tags.map((tag) => `      <category>${escapeXml(tag)}</category>`),
      `      <content:encoded>${cdata(html)}</content:encoded>`,
      "    </item>",
    ].join("\n");
  });

  return [
    '<?xml version="1.0" encoding="UTF-8"?>',
    '<rss version="2.0" xmlns:atom="http://www.w3.org/2005/Atom" xmlns:content="http://purl.org/rss/1.0/modules/content/" xmlns:dc="http://purl.org/dc/elements/1.1/">',
    "  <channel>",
    `    <title>${escapeXml(BLOG_META.title)}</title>`,
    `    <link>${siteUrl}${BLOG_PATH}</link>`,
    `    <description>${escapeXml(BLOG_META.description)}</description>`,
    "    <language>en-us</language>",
    `    <atom:link href="${siteUrl}${FEED_PATH}" rel="self" type="application/rss+xml"/>`,
    ...(newest ? [`    <lastBuildDate>${rfc822(newest.updated ?? newest.date)}</lastBuildDate>`] : []),
    ...entries,
    "  </channel>",
    "</rss>",
    "",
  ].join("\n");
}
```
